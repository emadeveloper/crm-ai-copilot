## Compact Rules (for sub-agent injection)

### Always (all delegations)
- Conventional commits only. Never add Co-Authored-By or AI attribution.
- Never run a build after changes.
- Shell: use `bat`, `rg`, `fd`, `sd`, `eza` — never `cat`, `grep`, `find`, `sed`, `ls`.
- Keep answers short; ask at most one question at a time, then stop.
- Verify technical claims before stating them; if the user is wrong, explain why with evidence.

### Python / backend (services/api)
- Hexagonal architecture: the domain layer MUST NOT import FastAPI, SQLAlchemy, httpx, or any vendor SDK. Vendors live behind ports (LLMProvider, CrmGateway, LeadRepository, TaskQueue) implemented in an adapters layer.
- Target tooling: pytest + pytest-cov, ruff (lint + format), mypy (strict). Pydantic v2 for boundaries, SQLAlchemy 2 style, Alembic for migrations.
- Prefer dependency injection over module-level singletons for adapters.

### Frontend (apps/web)
- React + Vite + TypeScript, installable PWA (vite-plugin-pwa), TanStack Query for server state.
- Consume the API through a generated OpenAPI client, not hand-written fetch calls.

### PR / issue workflow
- Issue-first: `issue-creation` before `branch-pr`. Never commit straight to the default branch.

### Review
- `judgment-day` on request for adversarial dual-review before merging significant changes.
